# ガクツク v3

すべての音楽へ携わり、始まりをシンプルにする。

ピアノ演奏を「録音 / YouTube / 音声ファイル」から自動で五線譜（大譜表）に変換するPWAアプリ。
子供でも使えるよう、大きなボタン＋ひらがな中心のUI。起動時は「ガクツク」の文字の真ん中に
足の生えた音符が歩いてきて座り込むスプラッシュアニメーション（タップでスキップ可）。

## 起動

- **ローカル**: `index.html` をブラウザで開く（`ガクツク.html` はリダイレクトのみ）
- **スマホ（iOS/Android）**: HTTPSでホスティングし（GitHub Pages等、seika-roplayと同じ方式でOK）、
  ブラウザで開いて「ホーム画面に追加」→ アプリとしてインストールされる（PWA）
- 初回はインターネット接続が必要。2回目以降はService Workerのキャッシュでオフラインでも動く（HTTPS配信時）

## アカウント

- **作成**: プライバシー文書を読む → ✅チェック → 同意 → 名前/誕生日/性別を入力
  → **英数5文字の個人ID**が発行される（例: J4TC7。紛らわしい I/O/0/1 は使わない）
- **初期パスワード**: 名前＋誕生日の月日（例: たろう0412）。⚙️からいつでも変更可
- **2回目からはログイン**（ID＋パスワード）
- **IDを忘れたら**: 作成時と同じ情報を入れると再表示できる（IDは情報のハッシュから決定的に導出されるため）
- **個人情報保護**: 名前・誕生日・性別は**保存されない**（ID導出と初期パスワード生成にのみ使用）。
  localStorageに残るのはIDとsalt付きSHA-256ハッシュのみ。検証済み（保存データに個人情報が含まれないことをテストで確認）
- **データ分離**: 楽譜ライブラリ・テーマはアカウントIDごとに完全分離（`gk_lib_<ID>`）。
  同じリンク・同じ端末を複数人で使ってもデータは混ざらない
- **管理者**: ID `master`（パスワードは公開リポジトリに書かない運用。オーナーに別途共有済み）。
  ホームに「👑かんり」が出て、アカウント一覧（ID・作成日・楽譜数のみ）と削除ができる。
  ⚠️ 公開後は ⚙️ から管理者パスワードを必ず変更すること

## サブスク化の準備

`CONFIG.SUBSCRIPTION.enabled` を `true` にすると `premiumFeatures`（youtube / pdf / midi）が
フリープランでロックされ、アップグレード案内が出る。決済（Stripe等）導入時は
ログインセッションに `plan: 'premium'` を設定すれば解除される。現在は全機能無料開放。
本格的な会員管理・課金を始める時は `Auth` オブジェクトをサーバー認証に差し替える前提の構造。

## バグ耐性の設計

- すべてのlocalStorageアクセスは `Store` ラッパー経由（壊れたJSON・容量超過でも落ちない）
- グローバルエラーハンドラで未捕捉例外を握り、ユーザーにトースト表示（黙って死なない）
- CDNはバージョン固定（vexflow@4.2.2 / basic-pitch@1.0.1 / jspdf@2.5.1）＋ SWキャッシュ
- スプラッシュはアニメーションが止まる環境でもsetTimeoutで必ず先へ進む

## 機能

| 機能 | 内容 |
|---|---|
| 🎤 録音 | マイクで演奏を録音→楽譜化（最大5分）。許可は各端末で初回1回だけ |
| 🎬 YouTube | PC: タブ音声キャプチャ（「音声も共有」をON）／スマホ: スピーカー再生をマイク録音 |
| 📂 ファイル | wav / mp3 / webm 等を読み込んで楽譜化 |
| 📚 ほぞん | 楽譜をlocalStorageに保存・一覧・再表示・削除（保存データは検出感度のみ変更不可） |
| 📄 PDF | A4縦・複数ページ対応のベクターPDF（jsPDF + svg2pdf、初回クリック時に読込） |
| 🎵 MIDI | 自前SMFライターで書き出し（MuseScore等で開ける） |
| 🎨 テーマ | 2色テーマ×4種（白黒/青白/ピンク白/黒青）。右上の丸で切替・保存される |

## 技術構成

- 音声認識: **Spotify Basic Pitch**（esm.run CDN）— 全てブラウザ内で解析、音声は外部送信されない
- 楽譜描画: **VexFlow 4** ／ 再生: sgm_plus 実ピアノサンプル ／ PWA: manifest + sw.js
- アイコン: icon-192.png / icon-512.png / favicon.ico（.NET Drawingで生成）

## 精度のための設計（v1から継承）

- **起動時セルフテスト**: 埋め込んだ実ピアノC4音を解析し正しく認識できる環境かを実測検証
  （壊れたGPU環境で「黙って間違った楽譜を出す」事故を防ぐ。結果はUAキー付きでキャッシュ）
- 録音時は echoCancellation / noiseSuppression / autoGainControl を全無効化
- モデル出力の生フレームを保持し、しきい値変更は再推論なしで即反映

## 開発メモ（重要な経緯）

- 当初のMagenta Onsets & Framesは同梱TF.js 2.7のWebGLが最新Chromeで数値破綻
  （C4→G#7のような誤認識を黙って返す）ため不採用。Basic Pitchへ切替済み
- 動作検証は**実ピアノ音**で行うこと（sgm_plusのp{midi}_v79.mp3を合成→handleAudioBuffer。
  合成サイン波は楽音と認識されない）。`window.gakutsuku` にテスト用フックあり
- ヘッドレスプレビューではCSSトランジション/スクリーンショットが進まない（実ブラウザでは正常）

## 制限事項

- マイク許可の「全デバイス共通1回」はOSの仕様上不可能 → 各端末初回1回（HTTPS配信ならブラウザが記憶）
- 認証はサーバー導入までは端末内ガード（本物のセキュリティではない）
- YouTube音声の直接ダウンロードは不可（規約/CORS）→ キャプチャ方式を採用
- リズムは量子化ベース（タイ・連符未対応）、テンポ一定を仮定
